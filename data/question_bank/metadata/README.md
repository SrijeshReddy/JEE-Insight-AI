# JEE InsightAI — Question Bank Metadata Documentation

This directory contains metadata, provenance logs, and audit reports for the JEE InsightAI Previous Year Question (PYQ) bank.

## Contents

- `source_README.md`: Raw upstream README fetched from Hugging Face (`soughed/jee-main-questions`).
- `audit_report.json`: Machine-readable audit generated by `scripts/audit_pyq_dataset.py`.
- `coverage_matrix.md`: Detailed subject, chapter, and paper coverage matrix.
- `provenance.json`: Source URLs, commit hashes, download timestamps, and licensing verification details.

Refer to `data/question_bank/README.md` for high-level dataset documentation.
